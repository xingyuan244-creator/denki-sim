# かんたん電気代シミュレーション

法人・個人事業主さま向けの、電気代の削減余地を試算する1ページのWebサイトです。
外部ライブラリ・CDNを一切使わない単一HTMLで、GitHub Pages でそのまま公開できます。

## 構成

| ファイル | 内容 | 公開 |
|---|---|---|
| `index.html` | シミュレーションサイト本体 | 公開ページ |
| `tools/qr.html` | QRコード作成＋印刷用POP／名刺カード生成（社内用） | 同じリポジトリのため閲覧可 |
| `tools/gas-mail.gs` | 問い合わせをメール転送する Google Apps Script | 同上 |
| `.nojekyll` | GitHub Pages の Jekyll 変換を無効化 | — |

## 公開URL

```
https://<ユーザー名>.github.io/denki-sim/
```

## 設定が必要な箇所

### 1. 問い合わせフォームの送信先（`index.html`）

未設定のままだと、送信者のメールソフトを起動する `mailto:` 方式で動作します。
自動でメール受信するには `tools/gas-mail.gs` の手順に従って Google Apps Script を
デプロイし、発行されたURLを設定してください。

```js
var SUBMIT_ENDPOINT = "https://script.google.com/macros/s/......../exec";
```

**設定後は `NOTIFY_EMAIL` を空文字にすることを推奨します。**
`mailto:` フォールバックが不要になり、メールアドレスが公開ソースから消えるため、
スクレイピングによる迷惑メールを防げます。

### 2. サイト名（`index.html`）

1か所書き換えると、ヘッダー・ブラウザタブ・送信メールの件名がすべて連動します。

```js
var SITE_NAME = "かんたん電気代シミュレーション";
```

SEO用に、HTML冒頭の `<title>` タグも同じ名前に揃えてください。

### 3. プライバシーポリシー（未対応）

フォームで個人情報を取得するため、プライバシーポリシーのページが必要です。
用意したうえで、同意チェックボックスのラベルにリンクを設定してください。

```html
<span><a href="/denki-sim/privacy.html">プライバシーポリシー</a>に同意して送信します</span>
```

## 流入経路の計測

URLに `?src=` を付けると、送信メールに経路が記録されます。
`tools/qr.html` で設置場所ごとにQRを作り分けてください。

| 設置場所 | URL |
|---|---|
| 店頭・卓上POP | `.../denki-sim/?src=pop` |
| 名刺 | `.../denki-sim/?src=meishi` |
| チラシ・DM | `.../denki-sim/?src=flyer` |
| 請求書同封 | `.../denki-sim/?src=invoice` |

## 試算ロジック

月間削減額 ＝ 入力された直近1ヶ月の電気代 × 15% を、**最も大きい位で繰り上げた金額**。

| 入力 | ×15% | 表示される削減額 |
|---|---|---|
| 80,000円 | 12,000 | 20,000円 |
| 45,000円 | 6,750 | 7,000円 |
| 350,000円 | 52,500 | 60,000円 |
| 60,000円 | 9,000 | 9,000円 |

業種・エリア・設備・契約数・契約先は金額計算に影響せず、
表示文言（施策の出し分け・見直しの優先度）にのみ使われます。

ブラウザの開発者コンソールを開くと、上記の検算6件が自動テストとして実行されます。

## ローカルでの確認

`index.html` をブラウザで直接開けば動作します（サーバー不要）。

## 免責

本シミュレーションは入力金額に基づく簡易試算であり、実際の削減額を保証するものではありません。
電力契約の勧誘・媒介を目的とするものではありません。

## 生成済みQRコード

`qr/` に、公開URL向けのQRコードを印刷用SVG（ベクター・拡大しても劣化しない）で同梱しています。

| ファイル | リンク先 |
|---|---|
| `qr/denki-sim-plain.svg` | `https://xingyuan244-creator.github.io/denki-sim/` |
| `qr/denki-sim-pop.svg` | 同上 `?src=pop`（店頭・卓上POP用） |
| `qr/denki-sim-meishi.svg` | 同上 `?src=meishi`（名刺用） |

他の経路タグや、印刷レイアウト込みのPOP・名刺カードは `tools/qr.html` をブラウザで開いて作成してください。
`tools/make-qr-svg.ps1` は、`tools/qr.html` が出力したモジュール行列からSVGを書き出すための補助スクリプトです。

## プライバシーポリシー

`privacy.html` に雛形を用意し、フォームの同意チェック文からリンクしています。
**公開前に、黄色くハイライトされた「要記入」箇所をすべて埋め、法務の確認を受けてください。**

- 事業者名・所在地・代表者名
- お問い合わせ窓口（メールアドレス・受付時間）
- 保有期間
- **第7条（第三者提供）** — 小売電気事業者等へ情報を提供する運用の場合、現在の条文は実態と一致しません。
  提供先・提供項目・目的・方法を明記し、フォームの同意文言も第三者提供に同意する旨へ修正が必要です。

記入が終わったら、`privacy.html` 冒頭の `<div class="notice">...</div>`（黄色い注意書き）を削除してください。

### 第三者提供について

問い合わせ内容を小売電気事業者等の提携先へ提供する運用のため、以下を反映済みです。

- `privacy.html` 第3条3号・第7条：提供先／提供項目／目的／方法／停止手続を明記
- `index.html` 同意文言：「提携先へ提供されることに同意して送信します」に変更
- `index.html` 安心材料の文言：「しつこい営業のお電話はいたしません」は提携先からの連絡と矛盾するため
  「お送りするのは、ご状況に合わせた試算とご提案のみです」「ご連絡の停止は、いつでもお申し付けいただけます」に差し替え

**第7条の「提携先の範囲」は具体的な事業者名の列挙を推奨します。**
包括的な記載のみの場合、本人の同意が有効と認められないおそれがあります。
